# Before You Begin Any Takeoff - Comprehensive Checklist

**Purpose:** This checklist ensures you have everything needed and have verified all critical information before starting a blueprint takeoff. Complete this checklist for EVERY project to prevent costly errors and omissions.

**Print this page and attach it to each project's takeoff package.**

---

## Project Information ☐

- [ ] **Project name and address verified** with builder/customer
- [ ] **Job number assigned** and recorded in your system
- [ ] **Builder/customer contact information** collected (phone, email)
- [ ] **Required completion date** or delivery deadline confirmed
- [ ] **Special instructions** from builder documented
- [ ] **Payment terms** and deposit requirements understood

---

## Plan Set Completeness ☐

- [ ] **Cover sheet** present with project index
- [ ] **All sheets accounted for** (compare sheet index to physical/digital set)
- [ ] **Architectural sheets** complete (site plan, floor plans, elevations, sections, details)
- [ ] **Structural sheets** present (framing plans, beam schedules, foundation details)
- [ ] **Schedules present** (windows, doors, finishes, room finishes)
- [ ] **Specifications** included (general notes, material specifications)
- [ ] **Addenda** checked (any late-issued changes or corrections)
- [ ] **Shop drawings** reviewed if applicable (trusses, engineered lumber)

---

## Revision Control ☐

- [ ] **Latest revision date** identified on cover sheet
- [ ] **Revision history** reviewed on each applicable sheet
- [ ] **All revision clouds** located and marked on your set
- [ ] **Delta symbols** matched to revision schedule
- [ ] **Superseded sheets** removed or marked "VOID - DO NOT USE"
- [ ] **Revision notes** read and understood
- [ ] **Your copy initialed and dated** to prove you reviewed current revision
- [ ] **Builder confirmed** this is the current set (verbal or written confirmation)

---

## Scale Verification ☐

**Critical: Never assume scale is correct. Always verify before measuring.**

- [ ] **Title block scale noted** for main floor plan (e.g., 1/4" = 1'-0")
- [ ] **Known dimension verified** (measure a labeled room dimension)
  - On paper: Used architectural scale ruler
  - On PDF: Used measurement tool at correct zoom
- [ ] **Scale discrepancy** noted if print is not to exact scale
  - If paper print scaled incorrectly: _____% variance recorded
  - If PDF: Zoom adjusted to _____ % to achieve correct scale
- [ ] **All sheets checked** (some plans use different scales on different sheets)
- [ ] **Detail scales noted** (details often use larger scales like 1" = 1'-0")

---

## Plan Orientation & Navigation ☐

- [ ] **North arrow located** on site plan and floor plans
- [ ] **Grid lines identified** (A-B-C horizontally, 1-2-3 vertically)
- [ ] **Legend/symbol key reviewed** for this particular plan set
- [ ] **Section markers noted** (bubbles showing where sections cut through)
- [ ] **Detail callouts identified** (circles referencing detail sheets)
- [ ] **Elevation markers** showing direction of view for each elevation
- [ ] **Page tabs or bookmarks** set for quick navigation between sheets

---

## Materials & Systems Identification ☐

**Foundation & Slab:**
- [ ] **Foundation type** identified (slab-on-grade, crawlspace, basement - SE Texas = slab)
- [ ] **Slab thickness** noted (typically 4")
- [ ] **Perimeter footing** dimensions verified (width × depth)
- [ ] **Interior beams** identified on foundation plan
- [ ] **Pier locations** marked if applicable
- [ ] **Concrete strength** specified (typically 3000 PSI minimum)
- [ ] **Rebar requirements** noted (#3 @ 18" O.C. typical for slab)
- [ ] **Vapor barrier** required (yes for SE Texas)
- [ ] **Anchor bolt spacing** specified

**Framing:**
- [ ] **Wall stud size** confirmed (2×4 or 2×6 exterior, 2×4 interior typical)
- [ ] **Stud spacing** specified (16" O.C. or 24" O.C.)
- [ ] **Plate material** identified (treated for bottom plate on slab)
- [ ] **Header schedule** reviewed for all openings
- [ ] **Engineered lumber** callouts noted (LVL, PSL, glulam)
- [ ] **Bearing walls** identified vs non-bearing partitions
- [ ] **Ceiling height** verified (8', 9', 10', or vaulted)

**Roof:**
- [ ] **Roof type** identified (gable, hip, complex)
- [ ] **Roof pitch** verified on each plane (e.g., 6:12)
- [ ] **Truss or stick-frame** confirmed
- [ ] **Overhang dimensions** noted (eaves and rakes)
- [ ] **Sheathing spec** identified (7/16" OSB or 15/32" plywood typical)
- [ ] **Roofing material** specified (architectural shingles typical)
- [ ] **Underlayment** requirements (felt, synthetic, ice & water shield)
- [ ] **Ridge vent** or other ventilation noted

**Exterior:**
- [ ] **Siding material** identified (vinyl, lap, board & batten, etc.)
- [ ] **Siding exposure** noted if applicable (for lap siding)
- [ ] **Trim details** reviewed (corner boards, fascia, frieze)
- [ ] **Soffit material** specified (vinyl, aluminum, wood)
- [ ] **Window type** confirmed (vinyl, wood, aluminum clad)
- [ ] **Door materials** specified (steel, fiberglass, wood)

---

## Regional Requirements (Southeast Texas) ☐

- [ ] **Slab foundation confirmed** (standard for high water table)
- [ ] **Treated bottom plates** specified for all walls
- [ ] **Hurricane/windstorm provisions** noted
  - Enhanced fastening schedules
  - Wind-rated shingles
  - Additional anchor bolts or straps
- [ ] **Humidity considerations** documented
  - Mold/mildew resistant materials
  - Proper ventilation specified
- [ ] **Coastal corrosion protection** if within 15 miles of coast
  - Galvanized or stainless fasteners
  - Treated or protected metals

---

## Special Conditions & Alternates ☐

- [ ] **Owner selections** identified (optional upgrades or choices)
- [ ] **Alternates** marked clearly (e.g., "Alternate siding: use vinyl instead of fiber cement")
- [ ] **Scope limitations** understood (what you ARE pricing vs what you ARE NOT)
- [ ] **Unusual conditions** flagged:
  - Curved walls
  - Vaulted or cathedral ceilings
  - Unusual roof geometries
  - Retaining walls or grade changes
  - Porches, decks, or covered patios
- [ ] **Clarifications needed** noted for builder follow-up

---

- [ ] **Calculator** (scientific or phone app)

- [ ] **Large work surface** cleared (plans need space to spread out)
- [ ] **Computer with Excel** ready and tested
- [ ] **Phone available** for builder questions if needed

- [ ] **Reference materials** within reach
- [ ] **Previous takeoffs** available for comparison if similar project

---

## Mental Preparation ☐

- [ ] **Adequate time allotted** (3-4 hours for typical house, don't rush)
- [ ] **Understanding of workflow** reviewed (Chapter 10 example)
- [ ] **Formulas refreshed** (stud spacing, slope factors, concrete volume)
- [ ] **Confidence level** assessed (ask for help if uncertain about anything)
- [ ] **Error-checking mindset** engaged (accuracy over speed)

---

## Common Mistakes to Avoid (Review Before Starting) ☐

**Scale & Measurement:**
- [ ] Never skip scale verification
- [ ] Don't assume all sheets use same scale
- [ ] Remember to convert inches to feet in calculations

**Stud Counting:**
- [ ] Don't forget the "+1" in stud formula
- [ ] Remember corner and intersection adds
- [ ] Account for king and jack studs at ALL openings

**Roof Calculations:**
- [ ] ALWAYS apply slope factor to horizontal area
- [ ] Don't confuse 6:12 with 12:6 (common error)
- [ ] Include waste factors (10-15% typical)

**Foundation:**
- [ ] Convert thickness from inches to feet before calculating
- [ ] Remember: cubic feet ÷ 27 = cubic yards
- [ ] Don't forget perimeter footing in addition to slab

**Documentation:**
- [ ] Document ALL assumptions
- [ ] Note any missing information
- [ ] Flag items needing builder clarification
- [ ] Show your work on complex calculations
